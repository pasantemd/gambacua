## Material adicional

Las marcas adicionales tienen carpetas propias: `aq1/`, `ubiquiti/` y `apc/`. `adicionales/` conserva accesorios, sistemas de alimentación y ambientación sin atribuirles una marca no confirmada. Ninguna carpeta de marca contiene subcarpetas: las imágenes están directamente dentro, con nombres descriptivos.
